# Подключение приложений

1. Согласовать обложки и описания; добавить Telegram-контакт команды.
2. SpaceRacing: подготовить отдельную копию, проверить работу в iframe, изолировать таблицу рекордов от рабочего webhook, проверить управление на телефоне.
3. WATERMAR: завершённый клиентский проект, а не демоверсия. Карточка хранится в каталоге. Перед запуском определить допустимый доступ к рабочему приложению и обработку заказов. Не копировать серверные данные и секреты в публичную папку.
4. Drago: пока только карточка. Исходный магазин и его внешние отправки не подключены.
5. Добавить экран запуска с явной кнопкой возврата, сохранением позиции каталога и управлением Telegram BackButton на стороне оболочки. Дочерние приложения не должны закрывать оболочку.
6. Проверить навигацию и safe-area в Telegram Android/iOS/Desktop, затем развернуть на HTTPS и привязать к боту.

Наличие папки само по себе не обеспечивает совместимость Telegram SDK во вложенном iframe. Передача данных и действия SDK требуют отдельной адаптации; проверка initData остаётся серверной.
