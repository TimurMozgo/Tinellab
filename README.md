# TINELLAB

Портфолио команды TINELLAB: сайты, Telegram Mini Apps и игры. Чёрно-бело-золотой интерфейс, плавная навигация, четыре снимка в каждом кейсе и запуск приложений внутри общей оболочки.

## Проекты

- WATERMAR — завершённый клиентский проект; просмотр каталога, без отправки заказов.
- MilitaryCoin — завершённый клиентский проект; локальный каталог. Цены и остатки не актуализируются.
- SpaceRacing — игра; локальный прогресс. Общий рейтинг и Telegram Stars не подключены.
- Atelier — демонстрация вёрстки, адаптированная под телефон.

## Локальный запуск

Статический сайт без обязательной сборки. Запустите статический HTTP-сервер в корне репозитория и откройте его URL в браузере. Для Telegram используйте HTTPS-адрес опубликованного сайта.

## Структура

```text
index.html             Главная страница
assets/css/            Стили
assets/js/             Навигация, загрузка, кейсы и форма
assets/screenshots/    Снимки проектов
data/projects.js       Карточки и описания
projects/              Браузерные версии приложений
```

## GitHub Pages

Публикация из ветки `main`, папка `/ (root)`. Файл `.nojekyll` включает выдачу статических файлов без Jekyll. После push GitHub Pages обновляет сайт автоматически.
